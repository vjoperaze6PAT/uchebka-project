# uchebka-project
# 📚 Учебка — всё для учёбы в одном месте

**Учебка** — это легковесное веб-приложение (SPA), которое помогает студентам организовать учебный процесс. Расписание, дедлайны, конспекты, флеш-карточки и Pomodoro-таймер — всё в одном окне, без необходимости регистрации и интернета (данные хранятся локально).

## ✨ Основные возможности (MVP)
- 🗓 **Расписание:** Просмотр пар по дням недели, добавление/удаление (с указанием аудитории, препода и типа занятия).
- ⏰ **Дедлайны:** Список сдач с дедлайнами и возможностью отмечать выполненные.
- 📝 **Конспекты:** Быстрые заметки по предметам (редактирование в реальном времени).
- 🃏 **Карточки:** Режим флеш-карточек для подготовки к зачетам (вопрос-ответ).
- 🍅 **Таймер:** Pomodoro-таймер на 25 минут с записью сессий.

## 🛠 Стек технологий
- **HTML5** (семантическая верстка)
- **CSS3** (кастомные стили, Flexbox/Grid, светлая минималистичная тема)
- **Vanilla JavaScript (ES6+)** (SPA-роутинг, работа с DOM)
- **LocalStorage** (хранение данных на стороне клиента)

*Выбор Vanilla JS обусловлен необходимостью создать легковесный MVP без накладных расходов на сборщики (Webpack/Vite) и фреймворки.*

## 🚀 Как запустить локально
Так как проект не требует сборки, достаточно:
1. Скачать файл `index.html`.
2. Открыть его в любом современном браузере (Chrome, Firefox, Safari).
*(Опционально: запустить через Live Server в VS Code).*
